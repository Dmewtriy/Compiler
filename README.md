### Цель работы

Создание кроссплатформенного графического интерфейса (GUI) для языкового процессора в виде специализированного текстового редактора.

## Описание проекта

Приложение представляет собой текстовый редактор, который в дальнейшем будет расширен до полноценного языкового процессора для анализа исходного кода.

**Основные возможности:**

* Работа с файлами (создание, открытие, сохранение с контролем изменений).
* Полноценный блок редактирования текста (отмена действий, работа с буфером обмена).
* Динамический интерфейс: редактор кода скрыт до момента создания или открытия файла.
* Индикация несохраненных изменений через заголовок окна (символ `*`).
* Предупреждения о потере данных при выходе или создании нового файла.


## Используемые технологии

* **Язык программирования:** C#
* **Платформа:** .NET (Windows Forms)
* **Архитектурный паттерн:** MVC
* **Среда разработки:** Visual Studio 2026


## Инструкция по сборке и запуску

1. **Клонирование репозитория:**
```bash
git clone [ссылка_на_репозиторий]
```

2. **Открытие проекта:**
Откройте файл решения `.sln` в среде разработки **Visual Studio**.
3. **Сборка (Single File EXE):**
Выполните следующую команду в терминале (в корневой папке проекта):
```bash
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```


4. **Запуск:**
Готовый исполняемый файл, не требующий установки .NET Runtime, находится по пути:
`./bin/Release/net8.0-windows/win-x64/publish/Compiler.exe`

## Диаграмма состояний
<img width="562" height="680" alt="image" src="https://github.com/Dmewtriy/Compiler/raw/master/resources/диаграмма.png" />
Краткое описание принципа его работы:

1. Начало работы (Состояние 0)
Автомат стартует из состояния 0. В зависимости от считанного символа (sc), он выбирает путь:
Буква или подчеркивание : переход в состояние 1 для обработки слов.
Пробел, скобки { } или точка с запятой ;: переход в соответствующие состояния (2, 3, 4, 5) для генерации кода конкретного символа.
Любой другой символ: переход в состояние ERROR.

3. Обработка идентификаторов и ключевых слов (Состояние 1)
Цикл (петля): автомат остается в состоянии 1, пока считывает буквы (Б), цифры (Ц) или подчеркивания (_).
Результат: по завершении цепочки автомат классифицирует слово:
code 2: если это зарезервированное слово enum.
code 3: если это зарезервированное слово case.
code 1: для всех остальных пользовательских имен (идентификаторов id).

5. Обработка одиночных символов (Состояния 2–5)

  * Состояние 2: пробел → code 4.

  * Состояние 3: фигурная скобка { → code 5.

  * Состояние 4: фигурная скобка } → code 6.

  * Состояние 5: точка с запятой ; → code 7.

4. Завершение (OUT)
После того как токен успешно распознан и его код сформирован, автомат возвращается в начало (OUT (start)) для чтения следующей порции данных.

```c

    CASE ID ';'
```
В грамматике под Flex&Bison специально вырезаны фрагменты нейтрализации ошибок с целью компактного изложения

### Классификация грамматики
Данная грамматика классифицируется как Контекстно-свободная грамматика (Тип 2) по иерархии Хомского. Левая часть каждого правила содержит ровно один нетерминал, а правая — любую комбинацию терминалов и нетерминалов.

### Примеры допустимых строк
Стандартный вариант:
` enum Status { case Active; case Closed; }; `

Пустой enum:
` enum a { }; `

Многострочный с подчеркиваниями:

```php
enum User_Role {
    case Admin_User;
    case Guest;
};
```

### Диагностика и нейтрализация синтаксических ошибок

**Метод Айронса**<br>
