Тема работы

Разработка текстового редактора с функциями языкового процессора. Объявление перечисления на языке PHP

Особенности языка

Перечисления в языке PHP — это специальные объекты, которые позволяют определить набор именованных констант. Они используются для представления типов данных, которые могут принимать только одно значение из ограниченного списка (например, статусы заказа или дни недели). Значения перечислений известны на этапе написания кода и не могут быть изменены во время выполнения программы.

Для описания перечислений используется ключевое слово enum.

Формат объявления перечисления в PHP следующий:

enum Suit {
    case Hearts;
    case Diamonds;
    case Clubs;
    case Spades;
    };

Примеры верных строк из языка

В соответствии с разработанной автоматной грамматикой синтаксический анализатор (парсер) перечислений будет считать верными следующие записи:

enum Suit{};
enum B { case A;};
enum _a { case A;};
enum _a {
      case _b1;
      case _v_2_;
      };
enum a1 {case b1;};
enum a2 {case b2;};
